# Khung code BTL Java - Quản lý sân bóng

## Công nghệ
- Java Swing
- JDBC
- MySQL
- Mô hình package: model, dao, view, database, main

## Cách chạy
1. Import file `database.sql` vào MySQL.
2. Mở project trong NetBeans hoặc IntelliJ.
3. Thêm thư viện MySQL Connector/J.
4. Sửa thông tin kết nối trong `DBConnection.java`.
5. Chạy file `quanlysanbong.main.Main`.

## Tài khoản demo
- Quản lý: admin / 123456
- Nhân viên: nhanvien / 123456

## Ghi chú
- Chức năng Quản lý tài khoản đã có code mẫu CRUD cơ bản.
- Các DAO khác đã có khung, bạn bổ sung SQL theo từng bảng.
